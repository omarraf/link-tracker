# Link Tracker Chrome Extension

A simple Chrome extension to track and manage links, especially useful for job applications.

## Features

- **Save Current Page**: Quickly save the current webpage you're viewing
- **Add Custom Links**: Enter any URL manually
- **Copy Links**: Copy individual links or all links at once
- **Delete Links**: Remove unwanted links individually or clear all
- **Clean UI**: Simple dropdown interface that doesn't get in your way

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" (toggle in the top right)
3. Click "Load unpacked" and select this folder
4. The Link Tracker icon should appear in your extensions toolbar

## Usage

1. Click the Link Tracker extension icon in your browser toolbar
2. Use "Save Current Page" to quickly save the page you're currently viewing
3. Or enter a URL manually and click "Add Link"
4. View all your saved links in the dropdown
5. Copy individual links or copy all links at once
6. Delete links you no longer need

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Main popup interface
- `popup.css` - Styling for the popup
- `popup.js` - Main functionality and link management
- `background.js` - Background service worker for extension lifecycle

Perfect for keeping track of job application links, interesting articles, or any URLs you want to reference later!
